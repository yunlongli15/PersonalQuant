# 新闻因子 PIT / 无未来函数审计

> 生成：`python scripts/news/audit_news_pit.py`
> 目的：证明 `as_of_date = T` 的因子读数**只用到了 T 及之前可用的事件**。

## 方法

对每个采样信号日 `T`：把事件集砍到 `availability_time <= T` 重算一遍，
与全量事件算出的 T 日读数**逐格比对**。只要有任何一处在 T 日读到了
T 之后才出现的事件，两个数就不可能相等。

采样：2015-01 ~ 2026-09 **每年一个调仓日**。抽样而不是全量，是因为每个采样日都要用砍过的事件集重算一遍面板（约 40 秒），全量跑要两小时而边际信息量为零 —— 因子对未来事件的敏感性不随日期变化。穷尽版本是合成数据的单元测试 `tests/news/test_news_no_future_leakage.py`。

范围：S3 实际消费的三个新闻因子（`announcement_count_20d` / `news_risk_20d` / `shareholder_change_count_20d`）。

## v1

事件 186,003 行 / 4,928 只股票 / 采样 12 个信号日

### 数据级

| 检查项 | 数量 |
|---|---|
| 事件总数 | 186,003 |
| `availability_unknown=true` | 1,071 |
| 其中却带着可用时间（口径矛盾） | 0 |
| 可用时间缺失（因子直接跳过） | 1,071 |
| **可用时间早于发布时间（时间倒流）** | **0** |
| 最晚可用时间 | 2026-09-30 11:40:11+08:00 |

### 因子级（截断不变性）

| 因子 | 比对格数 | 违约格数 |
|---|---|---|
| `announcement_count_20d` | 59,136 | **0** |
| `news_risk_20d` | 59,136 | **0** |
| `shareholder_change_count_20d` | 59,136 | **0** |

合计违约 **0** 格。


**结论：PASS —— 没有任何一处在 T 日用到了 T 之后的事件。**
