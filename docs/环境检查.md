## 关键发现与决策

1. **Python 版本冲突（重要）**：系统唯一 Python 为 3.13.8，但官方 PyPI 上最新版
   pyqlib 0.9.7 的 Windows wheel 最高支持 cp312（cp38–cp312 均有 win_amd64 wheel，
   无 cp313）。因此必须使用 Python 3.11/3.12 建立项目虚拟环境。
2. **决策**：通过 winget 以用户级（user scope）安装 Python 3.12（不修改系统 PATH
   上的 3.13，不触碰系统级 Python 环境），随后用它在项目内创建 `.venv`。
3. conda 未安装，故采用 `venv` 方案（比安装 conda 更轻量、无外部依赖）。
4. pip 默认指向清华 TUNA 镜像；该镜像对 pyqlib 无可用版本，因此本项目安装
   pyqlib 时显式指定官方 `https://pypi.org/simple` 索引。
5. **官方 CLI 数据集已禁用（重要）**：qlib 官方 README（v0.9.7 与 main 一致）声明
   “Due to more restrict data security policy. The official dataset is disabled
   temporarily”，官方推荐的替代数据源为社区维护的
   [chenditc/investment_data](https://github.com/chenditc/investment_data)。
   实测 `python -m qlib.cli.data qlib_data --region cn` 得到的 SunsetWolf v2/latest
   数据包缺少 Alpha158 必需的 `vwap` 字段，无法跑官方 workflow。
   因此按官方 README 指引改用 chenditc 数据包 `qlib_bin.tar.gz`
   （release 2026-09-04，538 MB，SHA256 与 manifest 校验一致），
   解压到项目 `qlib_data/`。该数据含 open/high/low/close/volume/amount/vwap/
   adjclose/factor/change 等完整字段，日历覆盖至 2026-09-04。
