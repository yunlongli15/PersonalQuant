## 分配方法（portfolio/allocator.py，注册表 portfolio_registry.py）

| 方法 | 数学形式 | 参数 |
| --- | --- | --- |
| P0 equal_weight | w_i = invest_target/K（冻结基线；**不施行业上限**，锚点可复现） | 无 |
| P1 score_weight | w ∝ f(score)，f ∈ {rank, raw_positive, softmax} | variant=rank |
| P2 inverse_vol | w ∝ 1/σ（σ 只用 <= signal_date 的收益） | 无 |
| P3 gmv | min w'Σw | 无 |
| P4 mvo | max μ̄'w − λ·w'Σ̄w，**归一化效用**：μ̄=μ/mean(\|μ\|)、Σ̄=Σ/mean(diag Σ)，λ ∈ {0.5 small, 2.0 medium, 8.0 large} | λ=medium |
| P5 risk_parity | min Σ_i (rc_i/Σrc − 1/K)²，rc = w∘(Σw)（long-only、无杠杆） | 无 |
| P6 turnover_aware | max μ̄'w − λrisk·w'Σ̄w − λturn·T − λcost·rate·T | λrisk=2.0, λturn=0.5, λcost=1.0 |

**换手统一定义（全局唯一）**：T = 0.5·Σ|w_new − w_old|，对候选与"被清出
的持仓"求和（被清出者的 |Δw| = w_old）。λ 固定默认值，不做网格搜索
（spec §65：不为好看调 λ）。

## 约束与 finalize（portfolio/optimizer.py）

- max_weight 10%、min 0、sector_cap 20%（硬上限）、cash_buffer（
  invest_target = 1 − buffer）、100 股手数、可选流动性上限
  （仓位市值 ≤ frac × 20 日均额）。
- 优化器解 → `finalize_weights`：先组级水位填充（行业预算 ≤ sector_cap
  分配 invest_target，饱和组不再加），再组内逐股水位填充到组预算
  （个股 ≤ max_weight/流动性上限）——精确、确定性、单遍。
- 不可行（cap 总和 < invest_target）→ AllocationFailure → 回退链
  （spec §44）：**方法 → inverse_vol → equal_weight**，最终结果始终携带
  optimizer_status + fallback_reason；全链失败则跳过本轮调仓并记录
  failed_all（绝不返回乱码权重）。

## 候选不足时的有效目标（frozen under-invest 语义）

MonthlyBacktest 的冻结语义：每股目标 = invest_target/top_k，与候选数量
无关。候选 n < top_k 时组合少投（现金更多）而非集中。引擎用
`effective_target(n, top_k, invest_target)` 缩放 allocator 的目标，
等权时每股权重保持 invest_target/top_k —— 与冻结引擎逐位一致
（anchor check：P0 ≡ strategy_v1_news，drift 0.0000）。

## 风险模型（portfolio/covariance.py）

- 估计器：sample / EWMA（halflife 30 交易日，归一化权重）；回看 60/120
  交易日；**PIT 铁律：只用 <= signal_date 的行**（tests/portfolio/
  test_covariance_pit.py + test_no_future_data.py：未来数据投毒不变性）。
- sanity gate：对称性 / PSD / 对角 > 0 / 条件数 / NaN 五项诊断；
  不稳定矩阵绝不静默进优化器 —— 修复链 sample/ewma → Ledoit-Wolf →
  对角（vols only），修复路径记录在 CovarianceResult.reason。
- 有效收益 < 20 的股票从协方差剔除并记录（excluded）。
- 风险贡献：marginal_i = (Σw)_i/σ_p；component_i = w_i·(Σw)_i
  （Σ = σ_p²）；share = component/σ_p²（每次调仓落盘）。

## 引擎（portfolio/backtest.py）

- 执行语义逐行对照 MonthlyBacktest：卖单先于买单、买单向下取整 100 股
  整数倍、减仓向上取整、T+1 开盘、涨跌停/停牌 NO_TRADE、共享
  TransactionCostModel、逐日 ffill 收盘盯市。
- 换手双口径：turnover（冻结口径，不含清仓卖出）+ turnover_full
  （含清仓）——两口径都报告。
- 每次调仓落盘：explainability（symbol/prediction/raw_rank/volatility/
  target_weight/industry/marginal_risk/contribution_to_risk/
  turnover_from_previous/action/optimizer_status/fallback_reason）+
  allocation audit（权重和/现金缓冲/个股上限/行业上限/无做空/无杠杆/
  可交易/手数/成交后现金/回退记录）。

## 研究纪律（选择协议先于结果写死）

scripts/portfolio/run_portfolio_study.py docstring 中预先写死的选择规则
（先于任何实验结果）：

1. top_k/cash：research Sharpe 最大 + valid ≥ 0.8× 稳定性门；
2. 方法：research Sharpe 最大 + valid ≥ 0.8× + 换手 ≤ 1.0 +
   research MDD ≥ P0 − 0.05；无方法通过 → 保持 P0（如实记录）；
3. 频率：仅当前 3 方法 quarterly 的 research+valid Sharpe 均 ≥ 0.9×
   monthly 时采用 quarterly；
4. frozen test 2024-2025 只评估一次，绝不用于选择；
5. research 期预测 = 年度 walk-forward（train 2015..Y-2、early-stop
   Y-1、预测 Y）；新闻覆盖 2018 起 → 2018-2019 模型为新闻盲期
   （如实记录），2020-2021 新闻生效。
