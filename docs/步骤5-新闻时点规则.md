# 步骤 5 新闻/公告时点（PIT）规则

## 1. 唯一可用性规则

新闻/公告在信号日 T（15:00 收盘）可用 ⟺ **availability_at ≤ T 15:00**，
其中 availability_at 由发布时间按下列规则确定（news/pit.py）：

| 发布时间 p | availability_at |
| --- | --- |
| 交易日且 time(p) ≤ 15:00 | p（盘中已知，收盘信号可用） |
| 交易日且 time(p) > 15:00 | 下一交易日 09:30 |
| 非交易日（周末/节假日） | 下一交易日 09:30 |
| 只有日期（time_unknown） | 下一交易日 09:30（**保守，不假定盘中已知**） |
| 发布日期未知 | availability_unknown=true，strict 模式禁用 |

- 例：2025-04-01 19:30 发布 → 2025-04-01 收盘不可用，2025-04-02 起可用。
- 周五 19:00 发布 → 周一 09:30 可用；春节（2025-01-28~02-04）期间的
  公告 → 2025-02-05 09:30 起可用。
- **event_time（事件发生时间）与 publication_time 严格分开**，因子研究
  只使用 publication/availability 时间。
- **updated_at 绝不代替 published_at**：2025-03-01 首发、03-03 更新的
  新闻，市场自 03-01 起知晓，不得因 updated_at 推迟可用时间。

## 2. 实现与测试

- 实现：news/pit.py（交易日历来自 canonical 缓存，与全系统一致）。
- 测试：tests/news/test_news_pit.py（盘前/盘后边界、仅日期、未知发布）、
  test_weekend_handling.py、test_holiday_handling.py（春节/国庆）、
  test_news_no_future_leakage.py（14 个新闻因子对未来事件不变）。
- 时区：全链路 Asia/Shanghai、timezone-aware（test_timestamp.py）。

## 3. 数据源时间戳质量

- SSE 官方公告 API：ADDDATE 精确到秒（盘后公告多为晚间时间）✓
- SZSE 官方 API：publishTime 精确到秒；部分为 00:00:00（仅日期 →
  time_known=False → 保守次日规则）✓
- CNINFO：epoch 毫秒；午夜时间戳视为仅日期 ✓
- AkShare（巨潮包装）：仅日期 → 保守次日规则

## 4. 信号日粒度

信号在每月最后一个交易日 15:00 生成；新闻因子窗口按**自然日**计算
（如 news_count_5d = 过去 5 个自然日内可用的公告数，非交易日无事件
计入 0），窗口内事件按 availability_at ≤ T 15:00 过滤。
