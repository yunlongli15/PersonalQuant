# 时点正确性（PIT）规则

财务数据必须严格区分**事实发生时间**（fiscal_period）与**市场可知时间**
（announcement_date），禁止用"2024 年年报"暗示"2024 年就知道"。

## 可用性规则

- `announcement_date` = 报告公告日（信息来源见
  `report_documents.announcement_date_source`）。
- `availability_date` = `announcement_date`；数据**从公告次日**起可用于研究
  决策：`可用 ⟺ as_of_date > availability_date`。
  - 2024 年报公告 2025-04-01 → 2025-03-31 回测**不可用**，2025-04-02 起可用。
- `availability_date_unknown = true`：公告日不可靠/未知（如 URL 派生日期
  超出合理窗口、源无公告日）——**strict mode 下禁止用于 PIT 回测**，研究引擎
  后续可用 `strict_mode=True` 开关（当前查询 API 即 strict）。

## 公告日来源与可靠性

| source | 含义 | 可靠性 |
| --- | --- | --- |
| sse_api | 归档项目 discovery 阶段的 SSE 官方 API 公告时间 | 高 |
| cninfo_url | 从 CNINFO PDF URL 路径 `finalpage/YYYY-MM-DD/` 派生 | 中（已做窗口校验） |
| sse_url | 从 SSE URL 日期段派生 | 中（已做窗口校验） |
| derived_invalid | 超出合理窗口（fiscal_year+1-06-30 之后或 fiscal_year 内） | **不可用** → 强制 unknown |

校验规则：年报公告日必须满足 `fiscal_year-12-31 < announcement_date ≤
fiscal_year+1-06-30`，否则标记 `derived_invalid` 并置 unknown（宁可 unknown，
不猜）。当前 63,612 行 metadata 中 127 行原始派生日期因此被降级为 unknown。

## 查询 API 行为

- `get_financial_metric(symbol, metric, as_of_date)`：返回 **as_of 时点最新可用**
  的指标（可能来自更早财年），附 value/source/announcement_date/
  availability_date/source_sha256。
- 存在报告但全部未到可用时点 → `NOT_AVAILABLE_AT_TIME`；
  无任何可公告日信息 → `NOT_AVAILABLE`。
- `get_financial_report(symbol, fiscal_year, as_of_date)`：同规则，strict 默认开。
- `get_latest_available_annual_report(symbol, as_of_date)`：PIT 下最新可用年报。

## 缓存层级

- LEVEL 1 metadata cache（report_documents）：永久。
- LEVEL 2 提取值缓存（financial_metrics）：永久；一旦成功提取不再下载 PDF。
- LEVEL 3 PDF 缓存（data/raw/reports/）：**默认关闭**；仅当 `cache=True` 或
  `PQ_PDF_CACHE=1`（复现/审计/debug）时保留实际用过的 PDF。
  31,000+ PDF 无需本地保存，只有真正用过的财务数据必须保留。

## 审计

每次提取写 `extraction_audit`：source_url / sha256 / page / section /
raw_value / normalized_value / unit / method / version / validation——
任何指标都能回答"从哪份 PDF 的第几页、用什么方法、何时提取"。
