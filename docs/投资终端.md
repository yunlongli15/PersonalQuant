# 个人投资终端（Streamlit）

```bash
source .venv/Scripts/activate
python scripts/run_app.py          # http://127.0.0.1:8501
python scripts/run_app.py --port 8600 --headless
```

只绑定本机；传 `--host 0.0.0.0` 会被直接拒绝（个人资产数据不出本机）。

## 定位

> 一个**完全本地运行**的个人投资研究、组合管理与决策辅助终端。

不是自动炒股机器人：**不连接券商、不自动下单、不涉及真实资金操作**。

## 与既有 FastAPI 界面的关系

项目里现在有两个前端，共享同一套引擎（`wealth/engine.py`），**没有第二套会计**：

| | `webapp/`（FastAPI，STEP 7） | `app/`（Streamlit，STEP 11） |
|---|---|---|
| 定位 | **录入型**：每日录入、交易流水、设置 | **终端型**：仪表盘、分析、研究浏览 |
| 页面 | 15 | 12 |
| 命令 | `python scripts/webapp/serve.py`（:8765） | `python scripts/run_app.py`（:8501） |

两者在"交易流水录入"上有功能重叠，未来应择一合并；本阶段不动 STEP 7 的
测试基线（见 `docs/步骤11-既有资产系统审计.md` §3.1）。

## 12 个页面

| 页面 | 内容 |
|---|---|
| **仪表盘** | 总资产 / 持仓市值 / 现金、净值曲线、资产配置、TWR/XIRR/回撤、当前策略卡、最新建议、最新新闻 |
| **持仓** | 全部持仓（可搜索/过滤/排序）、个股详情（价格图、成本、成交、策略信号） |
| **交易流水** | 流水列表、**记一笔**、**导入 CSV** |
| **调仓建议** | 买卖清单 + 结构化理由 + 调仓模拟；**只有导出，没有下单** |
| **量化策略** | 冻结配置卡、策略 vs 实际账户的权重偏离、当前信号 |
| **Paper Live** | forward holdout 起点/观测期/IC；样本不足时明确 NOT ENOUGH DATA |
| **风险** | 波动/回撤/VaR/CVaR/beta、行业暴露、集中度、收益贡献 |
| **因子** | 因子排行榜、增量 IC（STEP 9）、当前信号（**只读**） |
| **新闻** | 公告/新闻事件（方向/重要度/新颖度/风险）；LLM 输出单独标注 AI GENERATED |
| **回测** | strategy_v1 与组合研究的 NAV/Sharpe/MDD/IR（**只读**） |
| **研究** | 各阶段报告全文（**只读**） |
| **设置** | 系统健康 12 项、备份、导出、数据更新、界面配置 |

## 架构纪律

```
app/ (Streamlit 页面)     只做展示 / 输入 / 查询
    ↓  只允许调用
services/                 10 个服务模块（视图模型 + 编排）
    ↓  复用
wealth/  trade_plan/  pipeline/  factors/  portfolio/  paper_live/
                          （既有引擎，本阶段不重写）
```

**页面不允许 import 任何量化引擎**——有 AST 测试守着
（`tests/gui/test_app_import.py`），只允许 `streamlit / pandas / _shared /
services`。pandas 只用于把结果摆成表格。

**不自己实现 TWR / XIRR / P&L**：直接调用 `wealth/engine.py` 里已经存在
且有测试的实现（spec §49）。

## 空数据怎么办

服务层约定：任何一步取不到数据都返回

```python
{"available": False, "reason": "人话解释"}
```

页面显示明确的 **NO DATA** 和原因，而不是 Traceback（§60 / §67）。
`tests/gui/test_empty_states.py` 对 26 个服务接口逐一断言"不许抛异常"。

## 数据时间戳

每个页面顶部显示 **行情日期 / 信号日期**（§62）—— 避免误以为数据是实时的。

## 演示账户

没有真实账户数据时，用演示库看界面长什么样：

```bash
python scripts/make_demo_account.py
PQ_WEALTH_DB=data/wealth/demo.db python scripts/run_app.py
```

演示库是**独立文件**（`data/wealth/demo.db`），与真实库物理隔离 ——
真实财富库是"不可再生的个人状态"，一条演示流水混进去就再也分不清真假。

## CSV 导入

```bash
python scripts/import_portfolio.py --template          # 看格式
python scripts/import_portfolio.py trades.csv          # 默认 dry-run 预览
python scripts/import_portfolio.py trades.csv --apply  # 真正写入
```

格式：`date, symbol, side, quantity, price, fees, account`

- 列名支持中英双语（日期/代码/方向/数量/价格/手续费/账户）
- 方向支持 `BUY/SELL/买入/卖出/分红/转入/转出/拆股…`
- **幂等**：重复导入不会重复记账
- **不猜值**：认不出的方向、缺金额、日期格式错 → 报错并给出行号
- 每一条都经 `wealth/repository`，**自动写审计日志**

## 备份与恢复

```bash
python scripts/backup_portfolio.py                # 备份
python scripts/backup_portfolio.py --export       # 额外导出 CSV
python scripts/backup_portfolio.py --list
python scripts/backup_portfolio.py --restore FILE --confirm   # 恢复
```

恢复是不可逆操作：必须显式 `--confirm`，且**会先自动备份当前库**。
**不触碰任何市场数据**（DuckDB / Parquet 原样保留）。

## 安全边界

| 项 | 值 |
|---|---|
| 连接券商 | **禁止** |
| 界面改冻结策略 | **禁止** |
| API key | 只从环境变量读，**绝不写入 `config/gui.yaml`** |
| 绑定地址 | 仅 127.0.0.1 / localhost / ::1 |

`tests/gui/test_no_broker.py` 断言 GUI 与服务层里不存在任何下单/委托代码。
