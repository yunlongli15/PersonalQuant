# 步骤 3 执行模型

## 交易时点

- **T 日收盘**：生成信号（月度调仓日 = 每月最后一个交易日）。
- **T+1 日开盘**：执行交易（`execution.execute_order`）。
- 绝不允许"T 日收盘知道信号 → T 日收盘价成交"。

## 执行规则（保守，宁可不成交）

| 情形 | 处理 |
| --- | --- |
| T+1 无行情（停牌/长时间无成交） | NO_TRADE（跳过本单，持仓/现金保持） |
| 买入时 T+1 开盘 ≥ 昨收 × (1+0.095)（涨停） | NO_TRADE（不追涨停） |
| 卖出时 T+1 开盘 ≤ 昨收 × (1-0.095)（跌停） | NO_TRADE（不砸跌停） |
| 正常 | 按 T+1 开盘价成交 |

- 涨跌停阈值 0.095 配置于 `config/strategy_v1.yaml`（10% 制度）。
- 无法成交的订单本轮放弃；下月调仓重新计算目标仓位（自然补单）。

## 交易成本（TransactionCostModel，全部可配置）

| 项 | 参数 | 说明 |
| --- | --- | --- |
| 佣金 | 0.025%（买卖双向），最低 5 元 | **不代表任何券商实际费率** |
| 印花税 | 0.05%（仅卖出） | 2023-08 后的费率水平 |
| 过户费 | 0.001%（双向） | 保守简化 |
| 滑点 | 0.05%（单边，按成交额） | 保守假设 |

成本在成交时从现金扣减；后续可扩展历史税费制度（config 化）。

## 组合与手数

- Top 20 等权，每只目标权重 `(1 - cash_buffer) / top_k = 4.75%`，
  现金缓冲 5%（配置化，允许 0 / 0.05 / 0.10）。
- **买入手数**：向下取整到 100 股整数倍；理论 237 股 → 实际 200 股。
- **卖出**：清仓或减仓（减仓按 100 股向下取整，剩余保留）。
- 现金约束：先算目标市值，再按手数落地，现金余额自然吸收差额；
  成本从现金扣减。

## 回测记账

- 逐交易日走日历：T+1 应用成交（现金 ± 成交额 ∓ 费用），每日按收盘价
  标记组合市值 → NAV 序列。
- 换手率：`调仓成交额 / (2 × 调仓前权益)`（单边口径）。
- 每月预测全部落盘（prediction_date/symbol/predicted_return/rank/
  target_weight/model_version/dataset_version/feature_version），可复盘。

## 与现实的差距（诚实声明）

1. 成交价按 T+1 开盘价整单成交，未建模盘中冲击与部分成交（20 只 × 5%
   仓位在百万级资金下冲击极小，记录在案）。
2. 涨跌停判定只用了开盘价与昨收，未建模盘中开板（保守处理：宁可不成交）。
3. 停牌判定基于"T+1 无 K 线"（源数据无停牌标记），长期停牌在股票池层
   已用 max_absent_days 过滤。
