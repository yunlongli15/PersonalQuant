# 交易所公告库接入

## 上游项目

[sse-reports-archive](https://github.com/yunlongli15/sse-reports-archive)
（本地副本：`data/raw/sse-reports-archive/`，git 忽略）：
SSE 上市公司的年报归档系统。SSE 官方 metadata 主源 + CNINFO PDF 下载源。

**重要约束（用户明确要求）**：
> 禁止运行 `phase3b` 一次性下载 ~3.1 万份年报 PDF。
> 本系统只使用它的 metadata / URL / coverage / lifecycle；
> 除非某份 PDF 被真正需要（按需管线触发），否则不下载。

## 字段映射（PersonalQuant 自有 schema，非机械复制）

- 股票代码 → canonical symbol（`600000` → `600000.SH`）
- `document_role`：coverage 行 = `annual_report`；discovery 行按其标题分类
  （annual_report / annual_summary / correction / …）
- `announcement_date`：sse_api（discovery 行）> cninfo_url（URL 内嵌
  `finalpage/YYYY-MM-DD/`）> sse_url；派生日期经 PIT 窗口校验，
  越界 → `derived_invalid` + `availability_date_unknown=true`
- `source_url`：cninfo 行补全为 `https://static.cninfo.com.cn/{path}`；
  sse 行保留（SSE static 有 acw_sc__v2 WAF，只作 provenance，不下载）
- `status`：VERIFIED→verified、AVAILABLE→available、SOURCE_UNAVAILABLE→
  source_unavailable、MISSING→missing、NOT_APPLICABLE→not_applicable
- 归档中记录的 local_path/sha256：sha256 保留（251+ 行 verified），
  local_path 置 NULL（本机没有 PDF 字节，不伪造路径）
- 去重：同 (stock, year, role) 多源记录保留公告日信息最全的一行

## 按需获取（ReportDocumentProvider）

- `get_report_metadata(symbol, fiscal_year, report_type)` → metadata dict
- `get_report(symbol, fiscal_year, cache=False)` → 找到 CNINFO URL →
  单份 HTTP 获取 → `%PDF-` magic + ≥10KB + SHA256 校验 → 内存返回；
  `cache=True` 才落盘 `data/raw/reports/<sha256>.pdf`
- 重试/退避/随机延迟/单连接；404 → NotAvailableError；
  无可用 URL（WAF 的 sse 源）→ NotAvailableError（清晰失败状态）
