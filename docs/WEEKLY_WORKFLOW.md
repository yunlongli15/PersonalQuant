# 周度调仓操作流程

> ⚠️ **周度调仓不在系统验证范围内。** 冻结策略是月度调仓 + 20 交易日预测
> （frozen test Sharpe 1.022）。周度从未回测过，年交易成本约为月度的
> **3 倍**（≈4.2% vs 1.3%）。本流程用**同一个冻结信号**保证排序能力一致，
> 但把目标价/止损改为 **5 日预测分布**（系统已有的 1H/5D/20D 预测模块）。
> 是否采用由你判断。

---

## 一次性准备（本周买入前）

```bash
source .venv/Scripts/activate
python scripts/quant/refresh_all.py          # 刷新数据到最新交易日
python scripts/quant/write_recommendation_note.py --horizon 5
```

输出：`reports/paper_live/recommendation_<信号日>_h5.md`

按其中的**买入清单**手动下单：

| 列 | 怎么用 |
|---|---|
| 建议买入价 / 可接受区间 | 在区间内成交即可，不必强求计划价 |
| 股数 | A 股 100 股整数倍，已算好 |
| 目标价 | 5 个交易日内的模型目标（**不是保证**） |
| 止损价 | 跌破就走（**需要你自己在券商 APP 设条件单或手动盯**） |

**买入后请记录**：每只的实际成交价、股数、费用，剩余现金。

## 一周后的调仓（核心）

```bash
# 1) 刷新数据
python scripts/quant/refresh_all.py

# 2) 生成带持仓的调仓计划（把下面的数字换成你的真实持仓）
python - <<'EOF'
from trade_plan.plan import build_trade_plan, save_plan
plan = build_trade_plan(
    capital      = 100200,          # 你现在的总资产（持仓市值 + 现金）
    top_k        = 10,
    horizon      = 5,               # 周度
    holdings     = {                # 你现在实际持有（代码: 股数）
        '001360.SZ': 500,
        '002631.SZ': 1000,
        '300263.SZ': 1000,
    },
)
save_plan(plan)
import pandas as pd
df = pd.DataFrame(plan['rows'])
print(df[df.action != 'SKIP'][['symbol','name','action','current_price',
      'recommended_entry_price','shares','reasons']].to_string(index=False))
EOF
```

输出的 `action` 含义：

| action | 含义 | 你要做的 |
|---|---|---|
| **BUY** | 新买入（原来没有） | 按建议价买 |
| **ADD** | 加仓（持有但不足） | 补到目标股数 |
| **HOLD** | 维持（已到目标） | 不动 |
| **REDUCE** | 减仓（持有过多） | 卖掉一部分 |
| **SELL** | 清仓（已不在目标组合） | 全部卖出 |
| **SKIP** | 买不起 1 手 | 忽略 |
| **BUY_RESTRICTED** | 权限不足 | 忽略（科创板等） |

## 卖出判断（系统给原因，但不下单）

系统不监控盘中价格。你自己判断以下 6 条是否触发：

1. **到目标价** → 止盈
2. **跌破止损价** → 风控（可在券商 APP 设条件单自动执行）
3. **信号排名跌出前 K** → 逻辑变了（调仓清单里会显示 SELL/REDUCE）
4. **超过 10 个交易日**（周度版时间止损 = 2×5）→ 换股
5. **风险约束触发**（单只超上限）→ 减仓
6. **板块/资金变化** → 重新出计划

## 成本提醒（周度的主要代价）

| 频率 | 年调仓次数 | 假设换手 | 年成本 |
|---|---|---|---|
| 月度（已验证） | 12 | 55% | ≈1.3% |
| **周度（你现在做的）** | 52 | 40% | **≈4.2%** |

**多付出的 ≈2.9 个百分点/年**需要被策略收益覆盖。如果几周后发现
收益跑不赢成本，回到月度是更稳的选择。

## 常见问题

**Q：一周到了但我不想卖怎么办？**
A：没人强制。计划里的 SELL/REDUCE 只是建议；继续持有的风险是信号
可能已经失效（模型周期只有 5 天）。

**Q：能不能让系统每天提醒我？**
A：可以加"持仓监控"模块（每天对比目标价/止损/排名，输出该卖哪只、
为什么）。目前**没有**这个功能，需要我另外开发。

**Q：周度和月度哪个好？**
A：**月度有验证证据，周度没有。** 如果你问我的建议：用月度。周度只适合
你愿意承担更高成本、且能坚持每周操作的情况。
